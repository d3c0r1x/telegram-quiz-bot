# Telegram Quiz Bot

Викторина в Telegram: 10 вопросов, 4 варианта ответа, кнопки, счёт, лидерборд. Вопросы загружаются из бесплатного публичного API **OpenTDB**; при его недоступности используется встроенный оффлайн-пул.

## Команды

- `/quiz` — выбор сложности и начало игры
- `/leaderboard` — топ игроков (пагинация по 5 строк)
- `/stats` — статистика: количество игр, лучший счёт, точность в %, последние 5 игр

## Ход игры

```
/quiz
→ «Выберите сложность:» (любая / лёгкая / средняя / сложная)
→ Вопрос 1/10 с 4 вариантами
→ выбор варианта → «Верно!» / «Ошибка. Правильный ответ: ...»
→ итог: «Игра окончена! Ваш результат: 9/10»
```

## OpenTDB: особенности

- API бесплатный и без ключа (документация: https://opentdb.com/api_config.php), формат — `GET ...?amount=10&type=multiple` → `response_code` и массив `results`.
- **Вопросы содержат HTML-сущности** (`&quot;`, `&#039;`) — обрабатываются через `html.unescape` из stdlib.
- При перегрузке API возвращает `response_code=1` — бот переключается на встроенный русскоязычный пул вопросов.
- В демо-режиме (`QUIZ_DEMO_MODE=1`, по умолчанию) сеть не требуется.

## Защита от устаревших кнопок

Проблема: нажатие кнопки из **предыдущей** игры засчитывалось в новую. Решение: в `callback_data` включается nonce текущей игры; устаревшие кнопки отклоняются с алертом «кнопка устарела». Также предусмотрена очистка брошенных игр (сессии старше 30 минут удаляются, чтобы избежать роста потребления памяти).

## Интеграционное тестирование

Модульные тесты не покрывают полный конвейер обработки. Для этого написан `tests/test_live_flow.py`: **реальный Dispatcher** бота получает настоящие Telegram-апдейты (`/start → /quiz → выбор сложности → 10 ответов → /leaderboard → /stats`), а все исходящие вызовы Bot API перехватываются через `CapturingSession` — сеть не требуется, тест детерминирован. Отдельно проверены неверный ответ (отображается правильный) и устаревшая кнопка (отклоняется).

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export QUIZ_BOT_TOKEN=123456:ABC...   # токен от @BotFather
export QUIZ_DEMO_MODE=1               # 0 — реальный OpenTDB
python bot.py
```

На Windows — `run_bot5.cmd` (токен из корневого `.env`).

## Структура проекта

```
bot.py          — команды, игровой цикл, кнопки, nonce-защита
quiz_api.py     — запросы к OpenTDB, оффлайн-пул, построение URL со сложностью
db.py           — SQLite: статистика, лидерборд, журнал игр
middlewares.py  — троттлинг и логирование
config.py       — настройки из переменных окружения
tests/          — 10 тестов (7 unit + 3 интеграционных)
```

## Планы развития

- категории вопросов (не только сложность);
- таймер на вопрос;
- лига друзей: приватные комнаты для игры.

`pytest tests/ -q` — 10 тестов. GitHub Actions прогоняет их при каждом push.
